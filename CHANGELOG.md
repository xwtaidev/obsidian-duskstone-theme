# Changelog

## 1.0.0 — 2026-11-07

- Initial release of Duskstone for Obsidian.
- Warm taupe light mode and charcoal dark mode with muted semantic colors.
- Native reading, Live Preview and source editor styling; links, callouts, code, tables and properties.
- Rounded desktop sidebar and main-pane corners in expanded and collapsed states.
- Dark tab strip with readable icons, uninterrupted active-tab curves and native resize controls.
- Offline browser preview, sample note, print colors and manual-install archive.
